# 🚀 hh-resume-booster

> Userscript, который раз в 4 часа сам нажимает **«Поднять в поиске»** на hh.ru
> и держит резюме в верхних строках выдачи для работодателей.

## 📋 О проекте

hh.ru позволяет бесплатно поднимать резюме в поиске **раз в 4 часа**, но только вручную —
автоподнятие входит в платную подписку hh PRO. Этот скрипт делает то же самое бесплатно.

Работает **внутри обычного Chrome, в твоей настоящей сессии** — поэтому не упирается
в DDoS-Guard и антибот-защиту hh.ru. Официальный API для соискателей закрыт с 15.12.2025,
так что браузерный путь остался единственным.

Ни серверов, ни паролей, ни зависимостей: один файл на ~490 строк.

## ✨ Возможности

| | |
|---|---|
| 🎯 **Устойчивый поиск кнопки** | Ищет по `data-qa="resume-update-button"`, а если атрибут уедет — по видимой надписи |
| 💤 **Переживает сон ноутбука** | Хранит абсолютное время следующей попытки, а не таймер: проспанный слот отрабатывает сразу после пробуждения |
| 🛡 **Не трогает платное** | «Поднять автоматически» (hh PRO) и «Заказать рекомендацию за 799 ₽» отсекаются, даже если занимают место обычной кнопки |
| ✅ **Пять признаков успеха** | Клик считается удачным по любому из пяти независимых сигналов — не зависит от одной детали вёрстки |
| 🎲 **Разброс по времени** | К каждому сроку добавляются случайные 0–5 минут, чтобы поднятия не шли по идеальной сетке |
| 📊 **Живой статус** | Бейдж в углу страницы: статус, время следующей попытки, журнал последних 25 событий |

## 🔧 Установка

### 1. Поставить Tampermonkey

Открой [страницу расширения в Chrome Web Store](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
→ **«Установить»** → подтверди **«Установить расширение»**.

### 2. Разрешить Chrome выполнять userscripts

> ⚠️ **Не пропускай этот шаг.** Chrome по умолчанию блокирует пользовательские скрипты, и делает
> это молча: скрипт будет числиться установленным и включённым, а на странице не выполнится,
> без единой ошибки. Это самая частая причина «ничего не происходит».

1. Введи в адресной строке `chrome://extensions`
2. Найди карточку Tampermonkey → **«Подробнее» / «Details»**
3. Включи **«Разрешить пользовательские скрипты» / «Allow user scripts»**
4. Нет такого переключателя (Chrome старее 138)? Включи **«Режим разработчика»** тумблером
   в правом верхнем углу, затем вернись в «Подробнее»

Проверка: открой панель Tampermonkey — если наверху висит красная плашка про developer mode,
шаг не выполнен.

*В Firefox и Safari такого ограничения нет.*

### 3. Установить скрипт

```sh
git clone https://github.com/UshakovDev/hh-resume-booster.git
cd hh-resume-booster
cat hh-boost.user.js | pbcopy     # macOS
# xclip -sel clip < hh-boost.user.js   # Linux
```

Иконка Tampermonkey → **«Создать новый скрипт…»** → **Cmd+A** → **Cmd+V** → **Cmd+S**.

> Вставляй **вместе** с шапкой `// ==UserScript== … // ==/UserScript==` — это не комментарий,
> а конфигурация: там указано, на каких страницах скрипт запускается.

## ▶️ Первый запуск

1. Открой `https://hh.ru/applicant/profile/me` авторизованным *(hh сам перебросит
   на твой региональный поддомен)*
2. В правом нижнем углу появится бейдж **«hh · автоподнятие»**
3. Нажми **«Поднять сейчас»** — форсирует попытку, минуя собственный таймер скрипта

| Статус в бейдже | Что значит |
|---|---|
| 🟢 `поднято, ждём следующего окна` | Всё работает, дальше само |
| 🔵 `таймер hh ещё идёт` | Кнопка найдена, но 4 часа не прошли. Тоже успех — скрипт видит и кнопку, и таймер |
| 🔴 `кнопка не найдена` | hh поменял вёрстку. Посмотри, как подписана кнопка, и добавь текст в `BOOST_TEXTS` |

Дальше держи вкладку открытой — страница будет перезагружаться сама раз в ~4 часа.

## ⚙️ Как это работает

**Поиск кнопки.** Сначала по `data-qa="resume-update-button"`, затем — запасным путём — по
видимой надписи. Надпись проверяется в обоих случаях: во время четырёхчасового перерыва hh
подставляет на то же место платную «Поднять автоматически», и её трогать нельзя.

**Клик.** Последовательность `mousedown → mouseup → click`, подобранная под дизайн-систему hh
(magritte). Pointer-события убраны намеренно — с ними кнопка не срабатывает. Если за 4 секунды
нет отклика, скрипт добивает нативным `.click()`.

**Подтверждение.** Достаточно любого из пяти сигналов: кнопка исчезла из DOM, появилось
«Успешно поднято», изменилась дата резюме, hh отрисовал свой таймер, кнопка стала неактивной.

**Планирование.** Скрипт читает со страницы «Поднять вручную можно сегодня в 19:14» и запоминает
это как **абсолютную метку времени**. Долгих `setTimeout` нет намеренно: во сне ноутбука таймеры
замирают и уезжают. Раз в 30 секунд — а также при пробуждении вкладки, возврате фокуса и
восстановлении сети — часы сверяются с меткой.

**Перезагрузка.** Когда время подошло, скрипт перезагружает страницу: кнопка появляется только
в свежей разметке от сервера. Побочная польза — освежается сессия.

```
19:17  тикер видит, что время подошло   →  location.reload()
19:17  страница загрузилась, кнопка на месте  →  клик
19:17  подтверждение   →  следующая метка на 23:2x
```

## 🎛 Настройки

Все параметры — в блоке «Настройки» в начале [`hh-boost.user.js`](hh-boost.user.js):

| Константа | По умолчанию | Назначение |
|---|---|---|
| `MIN_INTERVAL` | 4 ч 2 мин | Собственный троттлинг поверх сайтового |
| `JITTER_MAX` | 5 мин | Случайная добавка ко времени попытки |
| `RETRY_DELAY` | 30 мин | Пауза после неудачной попытки |
| `LOGIN_DELAY` | 15 мин | Пауза, если сессия слетела |
| `MIN_RELOAD_GAP` | 5 мин | Минимум между перезагрузками |
| `TICK` | 30 с | Как часто сверяются часы |
| `WAIT_BUTTON` | 25 с | Ожидание появления кнопки |
| `WAIT_CONFIRM` | 15 с | Ожидание подтверждения клика |
| `MAX_FAILS` | 3 | После скольких неудач подряд остановиться |

## 🛡 Предохранители

- **Свой троттлинг** «не чаще раза в 4 часа 2 минуты» стоит поверх сайтового
- **Остановка после 3 неудач подряд** — чтобы при смене вёрстки не молотить перезагрузками.
  Снимается кнопкой «Поднять сейчас»
- **Минимум 5 минут между перезагрузками** — защита от петли
- **Платное не нажимается никогда** — надпись проверяется всегда, даже когда `data-qa` совпадает
- **Сессия слетела** → статус «не авторизован», тихое ожидание с проверкой раз в 15 минут

## 🐞 Отладка

**Бейдж не появился:**

1. Не выполнен шаг 2 установки — Chrome не разрешил userscripts
2. Не тот адрес: скрипт привязан к `*.hh.ru/applicant/*`
3. Скрипт выключен в панели Tampermonkey
4. Открой консоль (**Cmd+Option+J**) — при каждой загрузке скрипт пишет
   `[hh-boost] vX.Y.Z загружен: <адрес>`. Нет строки — скрипт не запустился, причина в пунктах 1–3

**Сломалась вёрстка hh.** В репозитории лежит [`debug-snippet.js`](debug-snippet.js) — вставь его
в консоль на странице профиля. Он снимет состояние карточки, отправит такой же клик, через
5 секунд снимет состояние ещё раз и выведет отчёт: html кнопки, что изменилось после клика
и прямой вердикт, работает ли клик.

## ⚠️ Дисклеймер

Автоматизация действий формально расходится с пользовательским соглашением hh.ru.
Один клик раз в 4 часа — очень тихий профиль, это не массовые автоотклики, но риск лежит
на аккаунте владельца. Официальная альтернатива — подписка **hh PRO** (199 ₽/нед,
автоподнятие 5 раз в сутки).

Скрипт не собирает и никуда не отправляет данные: всё состояние хранится локально
в хранилище Tampermonkey.
